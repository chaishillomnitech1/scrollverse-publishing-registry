# ScrollVerse Omni Manifesto

**A reader-directed public source index for the ScrollVerse ecosystem.**

## How to read this repository

Each entry is labeled as an **owner-authorized public source**. The entry records where a reader can inspect the repository and which ScrollVerse pathway it may inform. A public repository, README, description, design, contract, or workflow is not by itself a statement that a service is deployed, a product is for sale, a payment method is active, a contract is live, or a financial result has occurred.

# Release Boundary

## Purpose

This document separates source documentation from action. It keeps creative work, public sources, local route validation, public availability, and irreversible provider-side operations legible as distinct states.

| State | Meaning | What it does not mean |
| --- | --- | --- |
| Public source | A reader can inspect an owner-authorized public URL | A deployed service, sale, token, payout, payment method, or verified outcome |
| Local validation | A route, document, or test was checked in the local ScrollVerse workspace | Public publication or access through `scrollverse.co` |
| Public destination | A visitor-facing external address was checked and linked with its observed access state | An active checkout, product, payment method, or fulfillment flow unless separately shown |
| Release-ready | Source, rights, contributor, accessibility, destination, delivery, and owner-release fields are prepared | An activated listing, payment, token, or contract |
| Active external operation | A provider or public source directly records a live state | Authority to reproduce, alter, or activate it without its exact release record and confirmation |

## Irreversible-action rule

The following actions require an exact action statement and confirmation at the time of execution: publishing a product; opening or removing storefront access; enabling checkout; enabling or changing a payment method; changing a payout or provider setting; saving a market, country, currency, tax, duty, shipping, merchant-of-record, domain, or Tap to Pay setting; deploying a contract; minting or selling a token; or transferring funds or assets.

## Protected material

This public repository must never include credentials, secret keys, recovery codes, crawler signatures, API headers, account tokens, payment configuration, payout data, wallet seeds, private repository contents, or executable provider/deployment commands.

## Reader choice

The manifest gives readers a free route to inspect sources, local records, and release boundaries. It does not direct a visitor to buy, sell, invest, trade, mint, transfer, or align with any source.
