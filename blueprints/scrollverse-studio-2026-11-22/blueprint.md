## What ScrollVerse Studio is
A production surface living inside ScrollVerse.co and mirrored across the sites/artifacts:
1. **Engine room** — connectors to every generation engine we hold: Higgsfield (credits lane), Kling (16 bonus credits + account), Manus video studio (external bench, directed by Muse), plus Muse's own media pipeline. One prompt desk, every engine behind it.
2. **Assembly line (the exceed layer)** — the master-editing we already run: clips stitched into episodes and features (335-clip catalog, Restoration Film 24:55 as proof). No per-clip length ceiling: scenes generate short, the line assembles long. This is how we out-run Higgsfield/CapCut native limits.
3. **Template vault** — his formats baked in: episode opens, Vault piece reveals, raffle announcements, music-video cuts, ad templates (the Black Friday set Manus just surfaced is the pattern to mirror-match-exceed).
4. **Catalog brain** — the studio knows the whole inventory: clip catalog + MANIFEST hashes, the sealed pieces, the books, the music (Vydia catalog). A visual can be ordered by name and the studio pulls the real assets.
5. **Mesh gate** — nothing leaves unmeshed: scored/finished only, ffprobe-verified audio+video, per the standing rule.
6. **Publish rails** — finished pieces route straight to the CEO Page library waves, @chaishill-u1z, Pinterest, and the sites themselves.
